# setup-as-code Rust port: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `sac`, a single Rust binary with parity to the Node reference plus `apply --live`, fully tested, by 2026-10-16 09:30 ET.

**Architecture:** Dynamic `serde_json::Value` core (`Doc`), JSON-schema validation, read-only machine `Ctx`, trait-based importers and checks with an executable plugin protocol, planner diffing by layer collections, renderer to `out/` plus a merging live applier with backups. See the spec.

**Tech Stack:** Rust 2021 (rustc 1.97), clap 4, serde_json (preserve_order), serde_yaml 0.9, jsonschema 0.58 (no default features), plist 1, regex 1, walkdir 2, sha2, chrono, owo-colors, unicode-normalization. Dev: tempfile, assert_cmd, predicates.

**Spec:** `docs/superpowers/specs/2026-10-15-rust-port-design.md`

## Global Constraints

- Package name `setup-as-code`, binary `sac`, library crate `sac` (`src/lib.rs`).
- The manifest schema is `schema/setup.schema.json`, byte-identical to the reference's `framework/schema/setup.schema.json`.
- Behavioural reference is the Node code in `framework/` and `setup.mjs` at commit `f07590e`. Where this plan says "port exactly", match ids, field names, default values, status strings, ordering and message wording of the reference.
- Nothing under `~/.claude`, `~/.claude.json`, `~/Library/LaunchAgents` is ever written by any test or any command other than `apply --live --yes`, and tests run `apply --live` only against a temp home.
- No test reads the owner's real home; every test builds its own files under `tempfile::tempdir()`.
- No personal data in any source, fixture, test or doc: synthetic names only (`alex`, `example.com`, `com.example.*`). The lint is run over the tree before every commit.
- `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test` must be green at every commit.
- Paths in manifests are `~/...`; env var and header VALUES never appear anywhere, only names.
- Exec allowlist in `Ctx`: `launchctl list`, `launchctl print-disabled <domain>`, `crontab -l`, `sw_vers`, `uname`, `git -C <dir> remote|rev-parse|log` (never `set-url|add|remove`), `systemctl --user list-timers|list-unit-files`. Nothing else, ever.

## Review Focus

1. A plist whose `ProgramArguments` or `Label` is missing, or a binary plist, must import without a crash and without inventing a label from thin air other than the file name.
2. `settings.json` with no `permissions` key, or `permissions.allow` containing non-strings, must import with empty lists, not a panic.
3. A memory file whose frontmatter is not valid YAML must still count toward `files` and `by_type: unknown`.
4. `apply --live` against a home whose `settings.json` is malformed JSON must refuse and back nothing up, rather than overwrite.
5. `lint` must treat `han-redacted`-style instance names in paths as terms (whole-word, case-insensitive), and must not flag `example.com` emails or `/Users/alex` placeholders.

### Task 2: Machine importers (launchd, cron, infra, file-state) + external importer protocol + registry

**Files:** Create `src/importers/launchd.rs`, `cron.rs`, `infra.rs`, `file_state.rs`, `external.rs`; complete `builtin()` and `load_importers()` in `src/importers/mod.rs`.
**Reference:** `framework/importers/launchd.mjs`, `cron.mjs`, `infra.mjs`, `file-state.mjs`, `index.mjs`, spec section "Plugin protocol".
**launchd:** parse every `*.plist*` under `~/Library/LaunchAgents` and `~/Library/LaunchAgents/disabled` with `plist::Value::from_file` (XML and binary), convert to `Doc` (Date → RFC3339 string, Data → `"<data>"`). Rank 0 = `*.plist` not parked, 2 = suffix starting with `bak`, else 1. Status strings exactly as the reference (`installed`, `backup-only`, `parked`, `parked:<suffix minus trailing -?\d{6,8}>` or `parked:renamed`, `removed:override-disabled`, `removed:override-enabled`, `installed:override-disabled`, `running`, `loaded`, `installed:not-loaded`). `launchctl list` and `launchctl print-disabled gui/<uid>` only when `ctx.is_real_home()` and platform is macos; uid via `libc`-free route: parse `id -u`? No: use `std::os::unix::fs::MetadataExt::uid` of the home dir. Sort loops by id. `files` omitted when empty. Detect: macos and dir exists; but parsing must compile and run on Linux too (tests use fixtures on any OS).
**cron:** `crontab -l` only on real home; parse lines exactly as the reference.
**infra:** `machine { platform: darwin|linux|win32, arch, os }` (os from `/System/Library/CoreServices/SystemVersion.plist` ProductVersion on macos, `/etc/os-release` PRETTY_NAME or `uname -sr` on linux); `clis`: DEFAULT list + `opts.clis`, presence by scanning `PATH` in-process, `path` tilde'd; `repos`: for each `repo_roots` (default `["~"]`), dirs with `.git/config`, `remote` from the `[remote "origin"] url =` line with `//user:pass@` credentials stripped and scrubbed; no `last_commit`.

**external:** `ExternalImporter::load(path) -> Result<Self>` runs `<exe> describe`; `detect` runs `<exe> detect` (exit 0 = true) with env `SAC_HOME`, `SAC_REAL_HOME`; `run` pipes options JSON to stdin of `<exe> run` and parses stdout JSON. Timeout 20 s. `load_importers` = builtins, then every executable file in `<instance>/importers/` sorted by name, replacing a builtin with the same id.
**Tests:** XML plist with StartCalendarInterval array + WorkingDirectory + StandardOutPath → schedule calendar `["hour=9,minute=0","hour=17,minute=0"]`, program tilde'd, log tilde'd; StartInterval + KeepAlive → `every_seconds`, `keep_alive: true`; a `com.x.plist.killed-20260913` file → status `parked:killed`; `disabled/com.y.plist` → `parked`; `com.z.plist.bak` → `backup-only`; a plist missing Label → id from file name; a binary plist (write one with `plist::to_file_binary`) parses; sandbox home → installed loops `enabled: true, status: installed`; managed prefixes; cron parse of `*/5 * * * * cmd` and `@daily cmd`; infra repos from a fake `.git/config`; external importer via a `#!/bin/sh` script that prints JSON.
